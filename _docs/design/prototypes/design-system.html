05 · Iconography

Named glyphs, flexible sizing

Reusable UI icons share a 24px viewBox and inherit currentColor. Rendered dimensions belong to the consuming component and responsive CSS, not to the Icon API.

Base icon contract

iconName + currentColor
Component responsibility

The component selects the SVG only. Navigation, buttons, tables and responsive layouts set width and height in their own CSS.

.navIcon {
  width: 1.25rem;
  height: 1.25rem;
}

@media (max-width: 760px) {
  .navIcon {
    width: 1.125rem;
    height: 1.125rem;
  }
}
