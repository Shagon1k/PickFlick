# PickFlick final design package

Canonical design handoff assembled on 2026-07-22.

## Start here

- `index.html` — screen catalog and launcher
- `DESIGN.md` — canonical visual, responsive, interaction, motion, and asset rules
- `design-system.html` — visual component, typography, color, icon, and state catalog
- `ux-flow-map.html` — high-level product flows
- `responsive-baselines.html` — S / M / L / XL responsive reference
- `asset-catalog.html` — visual asset inventory
- `asset-manifest.json` — machine-readable asset inventory

## Included

- All current root-level HTML screens and design references
- Only PNG and WebP assets referenced by the included HTML surfaces
- Brand and design-system specifications
- Asset manifest and current critique metadata

All files remain in one directory so the prototypes' existing relative links continue to work.

The package contains 28 active image dependencies. Unused reference attachments and historical captures were removed from this delivery.

## Excluded intentionally

- `versions/` — historical snapshots
- `scripts/` — workspace utilities
- `plugin-source/` and `.od-skills/` — authoring infrastructure
- `*.artifact.json` — Open Design workspace metadata
- Unused image references and historical captures
- The previous roadmap — it is outdated and will be rebuilt from this package
